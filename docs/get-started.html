Installation

Two minutes, no dependencies

Every indicator is a single self-contained Pine script. There is nothing to build, no API key to obtain and no account to create anywhere.

Open the repository ↗Pick an indicator
Pine indicators

Copy one file into Pine Editor.

  1. Copy the script

    Open the .pine file you want from the repository and copy its whole contents.

  2. Paste and add

    In TradingView, open Pine Editor, paste over the default script, and press Add to chart.

  3. Set the timeframe

    Choose the projection or HTF timeframe in the settings, then check the chart-timeframe rule for that indicator in the table below.

  4. Add one alert

    For anything that notifies, create a single alert on the indicator with the condition Any alert() function call.

IndicatorChart timeframe rule
STATIC MODELAt or below the HTF you select.
STATIC Screener1–5m, and never above the scan timeframe.
Unicorn ModelYour execution timeframe; the three sources run above it.
OHLC Projection · CryptoEqual to or finer than the projection timeframe.
OHLC Projection · StocksEqual to or finer; prefer 1D and above.
Liquidity Sweep ProbabilityStrictly finer than the levels you display.
If load time suffers

Every pooled data feed and every extra confluence timeframe costs one request.security call, and Pine executes all of them whether or not you use the result. Turn off pooling and extra timeframes first.

Strat Scanner

Node 18+ and a phone.

The app runs through Expo Go — scan the QR code and tap Scan markets. The same engine runs headless for alerts, locally or on GitHub Actions.

  • No API keys — Yahoo Finance for most markets, Alpaca for crypto bars
  • Push notifications through ntfy.sh: pick a secret topic, set NTFY_TOPIC
  • Optional email copies via ALERT_EMAIL, forwarded by ntfy's bridge
More about the scanner → 
git clone https://github.com/jfreezy24-del/Deon20
cd Deon20/strat-scanner
npm install

npx expo start        # the app, via Expo Go
npm test              # engine unit tests
NTFY_TOPIC=... npm run alert

Publishing

GitHub Pages needs no workflow: repository → Settings → Pages → Deploy from a branch, then set the folder to /docs.

One more thing

These describe the past. They do not predict the next candle.

Every measured probability is a record of how a market has behaved, printed with the sample size behind it precisely so you can judge how much weight it deserves. Nothing here is financial advice.
