STATIC MODEL — Screener

The same setup logic pointed at up to forty symbols at once, from a single chart, with one alert per bar no matter how many of them fire.

How to installRead the source ↗
Two stages

An early warning and a signal, kept separate.

A setup that is still forming can un-form. The screener never pretends otherwise.

~

Forming

The live higher-timeframe candle has swept the prior candle's low or high and is trading back inside it. This is the heads-up: it can still un-form before the close, and the alert says so.

✓

Confirmed

The candle closed back above the swept low, or below the swept high. A valid C2. For the CISD confirmation and the entry itself, open the full STATIC MODEL on that symbol's chart.

Alert design

TradingView throttles noisy scripts. This one never gets close.

Every signal a chart bar produces is bundled into a single alert() message, one line per signal. The alert fires at most once per bar. Each stage also fires at most once per higher-timeframe candle per symbol, so a setup flickering in and out of "forming" doesn't spam you.

  • One alert on one chart covers the whole watchlist
  • Forming and confirmed can be toggled independently
  • The bias filter narrows the scan to one direction

Chart timeframe

The chart must sit at or below the scan timeframe — the script raises a runtime error otherwise. A 1–5 minute chart gives the fastest updates.

Setup

Three steps, one alert.

  1. Add it to a fast chart

    Any liquid symbol on a 1–5 minute chart. The symbol itself doesn't matter — the screener requests every symbol in your list independently.

  2. Paste your list

    Comma or newline separated, up to forty. Defaults ship with BTC, ETH, SOL, XRP, the Mag 7, SPY and QQQ. Set the scan timeframe — 4H by default.

  3. Create one alert

    Condition Any alert() function call, push notifications on. That single alert now covers the entire list.
